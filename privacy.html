Privacy Policy

Last updated: 17 October 2026

UNITY Assistant is a personal tool used only by its owner. It isn't available to the public.

What data it accesses

With the owner's permission, UNITY accesses the owner's own Google account data: Gmail, Google Calendar, Google Drive, Docs, Sheets and Contacts. It uses that data only to carry out tasks the owner asks for.

How data is stored

Access tokens are kept in the owner's local system keychain. Google data is processed on the owner's own computer and isn't sold, shared or used for advertising.

Google API Services

UNITY's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
